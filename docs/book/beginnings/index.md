# 第一篇 · 十二只，都回来了吗？

天快黑了，羊沿着小路回来。有几只在门口挤成一团，牧人刚数到这里，后面的又赶了上来。他说不准有没有少，便从头再数。山那边的光已经淡了，若真少了一只，还得趁天亮去找。

<ChapterImage file="beginnings-scene.png" alt="牧人在羊群附近摆石子，远处有村落和山地" caption="羊早上出栏，傍晚回来。两次清点隔了一整天。" eager />

本书的羊栏是虚构的教学场景，插画为 AI 生成。

## 把早晨留到傍晚 {#羊都回来了吗}

第二天，牧人在门边挂了一只空袋。出去一只羊，他就放进一颗石子。等羊走远，袋子留在原处。傍晚，回来一只，他就取出一颗。

<ChapterImage file="sheep-pairing.png" alt="早晨羊出栏时放入石子，傍晚羊归来时取出石子" caption="出去一只，放一颗。回来一只，取一颗。" />

假如每只羊只配对一次，袋子恰好取空，出栏和归栏的数量就对上了。还剩一颗，归栏数就少一个。他甚至不必先报出总数。石子已经替他把早晨留下来了。

## 从石子到数字 {#羊走远了-怎样记住数量}

羊多了，一袋石子沉，交给别人还得再数一遍。牧人换成木片，每出去一只就划一道。刻痕多起来，又可以分组数，把总数写成 12。

<RepresentationFigure />

从石子到刻痕，再到数字，变的是记法，留下的是同一个数量。我们把这个数叫作**标量**。它给了一个答案，代价是略去了各只羊的毛色、大小和身份。为了当前的问题有意保留某些方面，这就是**抽象**。

## 数一样，羊也一样吗？ {#只数羊-够不够}

有天傍晚，袋子空了。同伴在羊群里发现一只戴着邻家标记的羊。总数还是十二，可自家的羊有一只没回来。

<ChapterImage file="sheep-identity.png" alt="左右各三只羊和三颗石子，第三只羊的标记由绿色换成黄色" caption="取三只作对照。总数相同，第三只的标记却变了。" />

此后，牧人除了记总数，也把各只羊的耳标抄在清单上。点一下，看看同样的十二只怎样给出不同的核对结果。

<FlockCheck />

《墨子·小取》说过「夫物有以同而不率遂同」。放回这件事，就有了很具体的意思。**同样多、同一群、同一只，是三种不同的判断。** [《墨子·小取》](https://zh.wikisource.org/wiki/墨子/小取)

## 两个人怎样读同一份账？ {#一颗石子-究竟算几只羊}

羊又多了，他们分成甲、乙、丙三栏，各有人管。一天，两人交来两张都写着 12 的木片。一张记的是甲栏现在有十二只，另一张记的是乙栏今天有十二次过门。要汇总，得先问清在数什么。

<ChapterImage file="sheep-agreement.png" alt="两位牧人用手中石子说明一颗代表一只羊的约定" caption="交出记录时，也要交代别人该怎么读。" />

他们约定耳标的写法，给记录加上时间、羊栏和事件。A07 是羊号，归栏是动作。一次正式转栏还要记清来源和去向。

| 记下什么 | 例子 |
| --- | --- |
| 何时、哪只 | 16:10 · A03 |
| 发生了什么 | 转栏 |
| 从哪里到哪里 | 甲栏 → 乙栏 |

转栏让甲栏少一只、乙栏多一只，全场总数照旧。两边若各写一条，就要知道这是同一件事。**编码让记号有共同的读法，共同的记录规则让不同人的账可以一起算。**

荀子在《正名》中讨论名称怎样经由共同约定而获得通行的用法。牧人的例子很小，也用得上这层道理。 [《荀子·正名》](https://zh.wikisource.org/zh/荀子/正名篇)

## 怎样算出新结果？ {#记下来了-怎么算}

另一天，纸上已记下十一只。一只羊走进门来，牧人确认是自家的，便把十一加一，写成十二。已有的记录经过一次操作，给出了新答案。

<ChapterImage file="sheep-operations.png" alt="一只羊刚到入口，牧人在木板上更新刻痕" caption="确认一次归栏，记录随之加一。" />

## 算完，还要查什么？ {#算对了-事情就对了吗}

如果刚才那只在门口折返了，或者先前已经记过它一次，加法仍然算得对，账却错了。要查，就得拿归栏记录同眼前的羊对一遍。

<ChapterImage file="sheep-verification.png" alt="两位牧人拿刻痕板与羊的个体标记作核对" caption="算出来的结果，要能同现场对得上。" />

## 我们在算什么？ {#我们究竟在算什么}

**计算的本质，是按可执行的规则变换表示。** 这回答了怎么算。至于算得有没有用，还得问表示留下了什么、规则适不适用、结果能不能核实。

三个羊栏，每天都要处理这样的记录。牧人想把核对交给同伴，便说：「照昨天的办法做。」同伴却追问：「来了两条一模一样的记录，我取一次石子，还是两次？」
