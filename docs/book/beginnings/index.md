# 第一篇 · 人为什么需要计算

天色渐暗，一个人走到存粮的地方，停了下来。

今天分出去一些，剩下的够大家吃几天？外出的人明天能否带回食物？如果天气变坏，需要提前留下多少？

他眼前只有此刻的粮食，要作出的决定却关系到尚未到来的日子。他还需要同伴理解这笔安排，明天接手的人也要能继续核对。

这是本篇构造的一个生活情境。它让我们从一项具体困难开始：人要根据有限的所知，安排接下来的行动。

## 生活把问题带到面前

食物需要寻找和分配，工具需要制作与保管，同伴之间需要协作。人能支配的时间和资源有限，环境又会变化。行动之前，往往先有几个问题。

| 眼前的处境 | 需要知道什么 |
| --- | --- |
| 给每个人分食物 | 有多少，要分给几个人 |
| 找回外出的牲畜 | 回来的数量是否对上 |
| 决定何时出发 | 路程与可用时间是否相容 |
| 准备下一次分配 | 还剩多少，预计会用掉多少 |

有些判断可以凭熟悉的经验完成。看一眼篮子，觉得粮食尚多；走一段熟路，知道天黑前可以到达。数量增加、间隔拉长，或者需要把事情交给另一个人时，经验就遇到了新的负担。

“我记得还够”，怎样让同伴核对？“应该都回来了”，怎样发现记忆漏掉的一只？

人开始需要可以留下、可以比较、可以重复操作的依据。计算就在这样的需要中获得了用处。我们接下来关注数量、次序和条件能够怎样被明确处理，逐步走到可执行的计算。

## 留下一颗石子，把数量带回来

设想一个牧人，在每只羊出栏时放下一颗石子。傍晚回来一只，就取走一颗。最后剩下石子，意味着还有数量没有配对。

这个办法甚至可以先于“报出总数”的要求。牧人只要会逐个配对，就能回答“数量对上了吗”。

羊群离开了，石子还留着。眼前的一个对象，保存了关于远处对象的信息。

这里采用的是一一对应的思想实验。真实历史给我们留下的，是不同地方、不同阶段的记录实物。美索不达米亚乌鲁克的早期泥板账目，体现了物资收支对持久记录的需求。它们比古希腊和战国诸子的著作更早，把我们的问题带到了城市与行政协作的尺度。[1]

三只羊可以由三颗石子表示，也可以由三道刻痕表示。进一步写成“羊 · 3”，数量与类别就有了各自的位置。

![同一数量从羊群、石子、刻痕走到类别与数字的教学示意](/images/representation.svg)

*图中的排列用于解释表示的变化。不同工具在历史上有各自的使用背景。*

这里发生了一次抽象。记录保留了“有三只”这个关系，省去了羊的体形、声音和奔跑的姿态。凭这份简化的记录，我们能在羊群不在场时继续处理数量。

## 符号怎样让另一个人读懂

假如牧人离开，把三颗石子交给同伴。同伴却以为一颗代表一袋粮，记录虽然完好，理解已经走向了另一件事。

一份记录要被共享，使用者必须知道符号代表什么。这就把数量问题推进到了名称与约定。

战国时期，荀子在《正名》中讨论名称怎样确立，写道：

> 名無固宜，約之以命，約定俗成謂之宜。

这段话可以理解为，名称的合宜依赖共同形成并使用的约定。《正名》同时关心治理秩序、身份与名实，我们在这里借它追问共同理解的条件。[2]

把羊记作“羊”、写作另一种语言的词，或在表格中用一个约定编号，只要使用者遵守同一解释，就能指向所讨论的类别。编码要解决的正是表示与含义怎样对应。

但知道名称还不够。我们还得弄清，这个名称把哪些东西放在一起。

## “一样”，究竟是哪一种一样

三只白羊与三只黑羊，数量相同。白羊与黑羊都可以归入羊这一类。早上出去的三只羊，与晚上回来的三只羊，也可能数量相同。

这些“一样”回答着不同的问题。

| 要核对的关系 | 只留下“羊 · 3”够吗？ | 还可能需要什么 |
| --- | --- | --- |
| 是否同样多 | 可以核对数量 | 同一计数口径 |
| 是否都是羊 | 需要确认分类 | 识别类别的依据 |
| 是否原来的个体 | 数量记录无法独立确认 | 个体标记或其他识别信息 |
| 是否都健康 | 记录没有包含健康状态 | 检查项目与结果 |

如果混进来一只，恰好又丢了一只，石子仍然能够全部配完。这个反例让抽象的代价显现出来：**被省略的信息，不能仅靠保留下来的数量恢复。**

《墨子·小取》有一句简洁的话：

> 以名舉實，以辭抒意，以說出故。

用名称指称对象，用言辞表达意思，再说明理由。相关文本还提醒人们，事物在某一方面相同，其他方面未必随之相同。这些论辩属于后期墨家的思想积累，作者涉及学派成员。[3]

我们可以沿着这个问题检查自己的记录。看到两个“3”，先问它们数的对象、时间和范围是否相同。表示足够明确，后面的操作才有可靠的起点。

## 怎样从旧记录得到新答案

现在，一条记录写着“已归三只”，又回来一只。我们可以更新为四只。另一条记录写着“出栏四只”，把它与已归数量比较，可以判断数量是否对上。

现实变化被转换成了表示上的操作。

| 要回答的问题 | 对记录做什么 | 得到什么 |
| --- | --- | --- |
| 又回来一只后有多少 | 加一 | 新数量 |
| 出去与回来是否同样多 | 比较 | 相等或不相等 |
| 两群是否都数量对上 | 组合两个判断 | 条件成立或不成立 |
| 六份粮分给三个人 | 按分配约定逐人分发 | 每人两份 |

最后一行也留下一个前提。“每人两份”依赖这里采用平均分配。现实中谁该得到多少，还可能涉及需求、责任和共同认可的原则。运算可以检验一个安排的数量后果，安排本身的依据仍需要说明。

进制又处在另一层。十进制把十个一写成一个十，二进制每满二进一。它们约定数量怎样表示。加法、比较与逻辑，则规定输入确定以后怎样产生结果。

换一种写法，数量关系可以保持；换一条规则，同样输入就可能产生另一个结果。因此，记录的解释与操作的约定都需要清楚。

## 答案看起来对，怎样知道理由也对

人的直觉常能迅速给出一个答案。下一步是把它放到别人可以检查的过程里。

柏拉图《美诺篇》中，苏格拉底向一名被称为奴隶的少年提出几何问题。正方形的面积要加倍，边长是否也加倍？少年先作出肯定判断，追问与作图却揭示了问题。[4]

这个片段让我们看见提问的力量。一个人原先确信的答案，可以通过可检查的关系得到修正。对话还包含柏拉图关于知识与回忆的哲学讨论，读者可以沿原文继续研究。

亚里士多德进一步在《前分析篇》中分析，从已给前提怎样必然得出一个结论。[5] 沿用羊群，可以构造一个简短例子：

- 围栏中的每只羊都已经检查。
- 这只羊在围栏中。
- 所以，这只羊已经检查。

检查结论需要两步。先看前提是否真实，再看结论是否由前提支持。“这只羊已经检查，所以它在围栏中”就无法由相同信息保证，因为围栏外也可能有已检查的羊。

同一个实验里，我们也要分别核对输入、操作和结果。即使操作执行得很整齐，错误输入仍可能让结果失去现实依据。

## 写在外面，就已经理解了吗

记录能让信息离开现场、跨越时间。外部记录也让人能够把更多记忆任务交给工具。

柏拉图《斐德若篇》中，苏格拉底讲述一个关于文字的寓言。发明者把文字说成帮助记忆与智慧的工具，国王却质疑，人可能依赖外在记号，获得知道的表象。对话还指出，写下的文字受到追问时，会继续重复原来的话。[6]

文字已经能保存许多内容，理解它的人仍要承担解释和质疑的工作。一张写着“羊 · 3”的记录，不会自行告诉后来者，那是哪个牧人的哪一天，也不会回答数量是否经过复查。

这段寓言给本书留下一个可以不断回访的问题：**信息能够被保存、变换和表达以后，我们怎样判断它与现实相符，又怎样解释它？**

后面讲到程序、学习模型和语言生成时，这个问题会再次出现。我们将逐层检查每一种系统实际完成了什么，以及哪些判断仍需要额外证据。

## 从生活问题走到计算

回到开篇的存粮情境。现在，分粮的人可以记录库存和人数，约定一份的大小，按安排计算消耗，并在下一天用实际收支核对预计。

这个过程已经包含几项清楚的活动：

<div class="computation-path">
  <span>提出问题<small>剩粮够几天？</small></span>
  <span>建立表示<small>库存、人数、每人每日用量</small></span>
  <span>执行规则<small>求每日消耗，再比较可用天数</small></span>
  <span>解释与核对<small>供给是否够，假设是否成立</small></span>
</div>

这给我们一个理解计算的起点：

**把问题中关心的对象和关系表示出来，按明确规则操作这些表示，再把结果解释回原来的问题。**

在这个起点上，我们还要逐渐学习更精确的形式。哪些规则是可执行的？一个过程什么时候停下？一个装置怎样存住中间状态？有没有问题，无论怎样安排机械步骤都无法得到通用解法？

古代记录与哲学讨论为这些追问提供了材料。计数和记账早于通常所说的轴心时代，古希腊和先秦思想家后来从各自的问题出发，深入讨论了名称、知识和推理。它们的相遇发生在本书的阅读中，历史上的路线需要分别追踪。

下一篇，我们从核对多群羊开始，把比较、记录和重复安排成一套明确步骤。到那时，一个新的问题就出现了：如果别人能够照着做，装置能接手其中哪些部分？

## 原典与进一步阅读

文中石子、存粮和羊群情境是教学构造。下列资料分别支持历史背景与思想讨论。古文短引保留繁体，现代解释为本书作者的释义。

1. **早期书写与行政记录**。大都会艺术博物馆 Ira Spar，*The Origins of Writing*。可查看乌鲁克泥板实物及其经济管理背景。 [博物馆文章](https://www.metmuseum.org/essays/the-origins-of-writing)
2. **荀子《正名》第二十二篇**。重点读命名、同异及“名无固宜”所在段，同时留意其治理背景。 [原文](https://zh.wikisource.org/zh/荀子/正名篇)
3. **《墨子·小取》及后期墨家**。重点读“以名举实”与类推适用范围的讨论。 [原文](https://zh.wikisource.org/wiki/墨子/小取) · [学术导读](https://plato.stanford.edu/entries/mohist-canons/)
4. **柏拉图《美诺篇》82b—85b**。几何问答置于知识与回忆的讨论中。链接为 Benjamin Jowett 英译。 [对话全文](https://classics.mit.edu/Plato/meno.html)
5. **亚里士多德《前分析篇》第一卷，第 1—2 章**。阅读前提、三段论与推断方向。链接为 A. J. Jenkinson 英译。 [原文英译](https://classics.mit.edu/Aristotle/prior.1.i.html)
6. **柏拉图《斐德若篇》274c—277a**。文字寓言与对书写的讨论。链接为 Benjamin Jowett 英译。 [对话全文](https://classics.mit.edu/Plato/phaedrus.html)
