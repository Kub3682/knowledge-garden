# 第五篇 · 摄像头怎样知道羊进了门？

第一天用摄像头，账还是对不上。一只羊把头探进栏门，又退了出去。光看门口那一帧，它和刚刚进门的羊差不多。计数器只管照收到的消息加一，谁来判断这次该不该发消息？

<ChapterImage file="sheep-gate.png" alt="傍晚的栏门旁装着摄像头，一只羊停在门槛附近" caption="门口的一帧画面，只能告诉我们这一刻看见了什么。" />

## 多看一帧，会知道什么？

<CrossingFrames />

同一只羊从栏外经门口走到栏内，可以记一次归栏。若最后退回栏外，就没有完成这次归栏。连续画面提供了静止画面没有的**先后关系**。

| 手上的数据 | 怎样排成数 |
| --- | --- |
| 一帧彩色画面 | 高度 × 宽度 × 3 个颜色通道 |
| 一小段彩色视频 | 帧数 × 高度 × 宽度 × 3 个颜色通道 |

第四篇的数表有日期和羊栏两个轴。视频的数值也有自己的轴，帧、行、列和颜色。这种按多个轴组织的数值数组，在机器学习里称作**张量**。帧轴保存了先后，但形状本身还没有告诉机器哪串像素属于同一只羊。

## 怎样从看过的例子里学？

牧人从录像里挑出短片，标明「进栏」「折返」「看不清」，让训练程序对照模型的判断与标注，按误差调整模型参数。模型可以反复看不同样本，逐步调整怎样从画面和变化中作判断。

动作的定义仍由人给出。牧人可以明确说「从栏外进到栏内才算归栏」。难处是，在光线和遮挡不断变化时，从像素里找准那只羊并跟踪它。这是学习能帮忙的地方。新录像到来时，系统可以使用已经训练好的参数，无需为每段录像重新训练。

## 算成一个「1」之后，还剩什么？

拿训练时没用过的录像来试，换个羊栏、换到傍晚，再看看漏记和重复记了多少次。模型到了新条件下还能不能用，就是**泛化**的问题。挡住了耳标，可以记下疑似一次归栏，同时把羊号留作未知。

从大量像素到一次归栏，最后又可能只给计数器一个「加一」事件。第一篇的牧人也这么取舍过。他只留了一个数，便答不了是哪只羊回来。今天也一样，**要核对身份，仍要留下耳标、时间或可回查的片段。**

这天，归栏总数又到了十二。牧人打开电脑，没有找一列列数字，而是直接问：「A07 回来了吗？」
