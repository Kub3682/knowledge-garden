# 计算的本质

早晨出去十二只羊，傍晚也回来十二只。牧人本来要收起账本，却看见其中一只戴着邻家的耳标。

总数对上了。原来那十二只，真的都回来了吗？

<ChapterImage file="beginnings-scene.png" alt="牧人在羊群旁摆石子，远处有村落和山地" caption="起初，牧人只想在天黑前对清一笔账。" eager />

故事从一袋石子开始。后来，人们分栏记账，用机器处理记录，又把摄像头和栏门接入系统。每接手一件事，机器都要回答一个新问题。记录里有什么？怎样算？做完之后，怎么知道事情办妥了？
