# 少了一只羊吗？

羊群回来后，要确认数量是否对上。出栏一只，留下一颗石子。回来一只，取走一颗。

| 动作 | 留下的记录 |
| --- | --- |
| 三只出栏 | 三颗石子 |
| 两只归来 | 剩一颗石子 |
| 再回来一只 | 石子取完，数量对上 |

剩下的石子对应尚未配对的数量。这是一个思想实验，用来理解一一对应。

[亲手试试配对](https://kub3682.github.io/embedded-computing-atlas/#match)

## 为什么需要留下记录？

羊群离开后，石子仍能保存数量。盘点物资、核对发放，也会遇到跨时间确认数量的问题。

古代乌鲁克的行政机构需要记录物资收支，留下了早期泥板账目。沿着实物，可以看到记录如何服务于核对。

[大都会艺术博物馆 · 书写的起源](https://www.metmuseum.org/essays/the-origins-of-writing)
