# 羊群不在眼前，还能怎样记下来？

三只羊要带三颗石子。羊再多一些呢？可以把数量写下来。

![从羊群到石子、刻痕和数字的表示对照](/images/representation.svg)

图中是教学示意。读者知道约定，就能从「羊 · 3」读回类别与数量。

## 同样的记录，可以代表不同东西吗？

三颗石子可以代表三只羊，也可以代表三袋粮。需要先约定每颗代表什么。数字 3 表达数量，类别说明在数什么。

**编码建立表示与含义之间的约定。**

## 乌鲁克的泥板账目

公元前第四千纪末，美索不达米亚的城市管理需要记录物资收入与分配。泥板上的数量记号和物资符号让账目得以保存和核对。

[查看泥板实物与书写史](https://www.metmuseum.org/essays/the-origins-of-writing)

## 绳结也能记账

印加人曾用结绳记录贡赋、人口和交易。读取记录，需要了解绳与结的约定。

[大都会艺术博物馆 · 印加结绳记录](https://www.metmuseum.org/de/toah/ht/08/sanc)
